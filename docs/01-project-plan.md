# 📋 خطة المشروع - محفظة المنزل (Home Wallet)

## نظرة عامة على المشروع

**اسم المشروع:** محفظة المنزل (Home Wallet)  
**النوع:** تطبيق ويب شخصي لإدارة مصروفات الأسرة  
**تاريخ البدء:** فبراير 2026  
**الحالة:** قيد التطوير

---

## 🎯 أهداف المشروع

1. تطبيق بسيط وسهل الاستخدام لتتبع مصروفات الأسرة
2. واجهة مستخدم عربية بالكامل مع دعم RTL
3. تصميم متجاوب (Mobile-First)
4. استضافة مجانية على GitHub Pages

---

## 👥 المستخدمون

| المستخدم | الدور  | الصلاحيات                 |
| -------- | ------ | ------------------------- |
| الزوج    | مستخدم | إضافة/تعديل/حذف مصروفاته  |
| الزوجة   | مستخدم | إضافة/تعديل/حذف مصروفاتها |

**ملاحظة:** لا يوجد تسجيل عام - فقط المستخدمين المحددين مسبقاً يمكنهم تسجيل الدخول

## 🛠️ المتطلبات التقنية

### Stack التقني

| التقنية      | الإصدار | الغرض                      |
| ------------ | ------- | -------------------------- |
| Vue.js 3     | ^3.5.27 | إطار العمل الأساسي         |
| Vite         | ^7.3.1  | أداة البناء                |
| Vue Router   | ^5.0.1  | التوجيه                    |
| Pinia        | ^3.0.4  | إدارة الحالة               |
| TypeScript   | ~5.9.3  | Type Safety                |
| Tailwind CSS | ^4.1    | التصميم (Mobile-First)     |
| Firebase     | ^12.x   | Authentication + Firestore |

### متطلبات الاستضافة

- GitHub Pages (استضافة ثابتة)
- Hash-based routing (لتوافق GitHub Pages)
- Base path: `/home-wallet/`
